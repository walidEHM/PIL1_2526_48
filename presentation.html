Architecture du projet

Description de la conception

03

Frontend

Le frontend est développé avec HTML5, CSS3, JavaScript et Bootstrap 5. Il gère les pages d'accueil, de profil, de matching, d'annonces et de messagerie.

Backend

Le backend utilise Django avec Python. Il prend en charge l'authentification, le traitement des données, l'algorithme de matching et les échanges avec la base de données.

Base de données

MySQL stocke les utilisateurs, les compétences, les disponibilités, les annonces, les demandes, les matchs et les messages.

  • accounts/ : gestion des utilisateurs et authentification.
  • matching/ : gestion des annonces et algorithme de mise en correspondance mentor-mentoré.
  • messaging/ : gestion de la messagerie instantanée.
  • templates/ : pages HTML de l'application.
  • static/ : fichiers CSS, JavaScript et images.
  • database/ : fichier SQL de sauvegarde de la base de données.
  • manage.py : point d'entrée principal du projet Django.

Installation et lancement

Instructions de déploiement

05

Prérequis

Python 3.x, MySQL et Git doivent être installés avant l'exécution de l'application.

1. Cloner le dépôt

git clone <lien_du_depot> cd PIL1_2526_48

2. Créer l'environnement virtuel

python -m venv venv venv\Scripts\activate

3. Installer les dépendances

pip install -r requirements.txt

4. Configurer MySQL

CREATE DATABASE mentorlink_db; mysql -u root -p mentorlink_db < mentorlink_project/database/mentorlink_db.sql

5. Configurer Django

copy mentorlink_project\.env.example mentorlink_project\.env

6. Lancer Django

cd mentorlink_project python manage.py runserver

7. WebSockets

daphne mentorlink.asgi:application

Adresse d'accès : http://127.0.0.1:8000

Guide utilisateur

Manuel d'utilisation

06

Création d'un compte

  1. Accéder à la page d'accueil.
  2. Cliquer sur « S'inscrire ».
  3. Renseigner le nom, le prénom, l'adresse e-mail, le téléphone, le mot de passe, la filière et le niveau.
  4. Ajouter les compétences, les lacunes et les disponibilités.
  5. Valider l'inscription.

Connexion

  1. Cliquer sur « Se connecter ».
  2. Saisir son e-mail ou son numéro de téléphone.
  3. Entrer son mot de passe.
  4. Cliquer sur « Connexion ».

Gestion du profil

  1. Accéder à son profil.
  2. Ajouter la photo, la filière et le niveau d'études.
  3. Indiquer les compétences, les lacunes et les disponibilités.
  4. Enregistrer les modifications.

Recherche de mentorat

  1. Consulter les offres ou demandes de mentorat.
  2. Utiliser les filtres de recherche si nécessaire.
  3. Sélectionner un profil ou une annonce correspondant à ses besoins.
  4. Démarrer une conversation avec l'utilisateur concerné.

Système de matching

  1. Accéder à la section « Matching ».
  2. Consulter les recommandations proposées.
  3. Visualiser le score de compatibilité.
  4. Choisir un mentor ou un mentoré.

Messagerie et déconnexion

  1. Ouvrir la section « Messages ».
  2. Sélectionner ou démarrer une conversation.
  3. Envoyer et recevoir des messages.
  4. Se déconnecter depuis l'icône du profil.
Retour d'expérience

Difficultés rencontrées

07
Durant la réalisation du projet MentorLink, plusieurs difficultés ont été rencontrées, aussi bien sur le plan technique que sur le plan organisationnel.

Sur le plan technique, la mise en place de l'environnement Django a nécessité plusieurs configurations, notamment l'installation des dépendances Python, la connexion à la base de données MySQL et la gestion des migrations. Certaines erreurs liées à la structure du projet et aux relations entre les modèles ont également été rencontrées.

Une autre difficulté concernait la gestion des relations entre les utilisateurs, leurs compétences, leurs disponibilités et leurs profils. Il a fallu organiser correctement les différentes applications Django afin de rendre le projet plus clair et plus maintenable.

Sur le plan organisationnel, la coordination du travail en équipe a demandé une bonne répartition des tâches. L'utilisation de GitHub a permis de structurer les contributions, de suivre l'évolution du projet et de limiter les conflits de code.
Bilan du projet

Conclusion

08

Le projet MentorLink a permis de concevoir une plateforme de mentorat destinée à faciliter la mise en relation entre mentors et mentorés. Cette application vise à améliorer l'accompagnement des étudiants dans leur parcours académique en leur permettant de trouver plus facilement de l'aide selon leurs besoins, leurs compétences et leurs disponibilités.


La réalisation de ce projet a permis aux membres du groupe de mettre en pratique leurs connaissances en développement web, en Django, en gestion de base de données, en conception d'architecture logicielle et en travail collaboratif.


En perspective, le projet pourrait être amélioré par l'ajout d'un système de matching plus intelligent, éventuellement basé sur l'intelligence artificielle, ainsi que par l'amélioration de l'interface utilisateur et le renforcement de la sécurité.
